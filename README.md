# David Chan — Portfolio

Static portfolio with project galleries, films and an interactive pixel studio.

- `index.html`: main portfolio and project detail pages.
- `variant-b/index.html`: alternative portfolio with a full-screen opening, desktop/mobile scroll exhibition and an expanded More work collection.
- `variant-b/solomission.html`: dedicated SoloMission case study.

Run `python3 -m http.server 4173 --bind 127.0.0.1` and open `http://127.0.0.1:4173/variant-b/` to preview.

All runtime files and media are included. No build step, API key or backend is required. GitHub Pages can serve the repository root. The original repository history preserves the earlier website.
